# Classroom for Mac

Classroom for Mac is an unofficial, native Rust and Iced macOS client. The interface uses the Classroom web app's class grid, sidebar and course tabs as a reference. Rendering and ordinary navigation stay in the native app. Google sign-in opens separately in an isolated browser.

## Open the app

Open **Classroom for Mac.app** on an Apple Silicon Mac. Enter your Google Workspace email and choose **Sign in with Google**. Complete sign-in in Google's window. **Try demo** opens synthetic classes without contacting Google.

The first Classroom read is the course list. Normal sign-in requests course state and theme along with class names. Home and the sidebar exclude archived classes. Choose **Archived classes** in the sidebar to see them. Courses without a reported state stay visible on Home.

Home also reads your personal class visibility. Hidden classes stay enrolled and are kept out of Home, the sidebar, To-do and Calendar. Open a card’s menu to hide it, or expand **Show hidden classes** at the bottom of Home to unhide it.

In **Classroom order**, drag a class by the grip on its card. You can also open the card’s **Move** menu and choose the beginning, the end, or a position after another visible class. Home and the sidebar update after Classroom confirms the order.

Use **Open link…** to paste a Classroom class, classwork, assignment or question URL. The app resolves it against the current account or offline copy. The class and item views have copy buttons for the supported Classroom URLs.

Due soon, Stream, Classwork, People, Your work, To-do, Calendar, invitations and assignment details load automatically on navigation. Loaded content stays visible while another section finishes. A failed read shows Retry in the affected section. Leaving and reopening the page also retries it. If a comment send ends without a confirmed result, the open thread reloads automatically and the draft stays available.

The app uses the returned theme colour and prefers the Material 3 banner URL when available. It loads returned Google-hosted artwork into memory without sending the session credential. The app validates each HTTPS redirect before requesting the next image URL. The exact web palette ordering and presentation still need a side-by-side comparison on a live account. The embedded Google Sans Flex font is distributed under its SIL Open Font License in `assets/fonts/OFL.txt`.

Normal sign-in saves the Google master credential in macOS Keychain. The app restores the session on reopen and renews an expiring token when needed. If Google requires a fresh sign-in, choose **Reconnect** to open Google's window while keeping the current page. **Sign out** removes the saved credential. The short-lived token stays in memory. Sign-in uses an unofficial Android route that Google can change or reject.

Use **Save offline copy** only if you want a local copy of the courses and loaded work. The app keeps that account's copy in an SQLite database accessible to the macOS user. Cache contents are not encrypted. Roster entries, comments, submissions, grades and artwork URLs remain in memory. Use **Remove offline copy** while signed in to delete that copy.

## Build again

The development workspace already contains the local sign-in runtime. Build the ARM64 application with Cargo and `protoc` installed:

```sh
cargo build --release --locked --features desktop --bin classroom-desktop
cargo test --locked --features desktop --all-targets
```

Run the built binary with `--screenshots /path/to/output` to render synthetic dashboard, classwork, Your work, To-do and calendar PNGs, including question editors and the calendar at minimum window size. Run `swift tests/desktop_capture.swift /path/to/output` to check that both short-answer drafts render in the standard-size captures. The macOS packaging script at `desktop/package-macos.sh` takes the built binary and an app destination. It signs and verifies the new bundle before replacing a previous Classroom for Mac build at that path. This build uses a local ad hoc signature.
